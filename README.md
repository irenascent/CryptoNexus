# CryptoNexus

CryptoNexus enables secure, end-to-end encrypted, decentralized transactions via distributed network gateway protocol.

With CryptoNexus, you get a lightweight tool that stays out of your way.

**What you get**

- CryptoNexus enables secure, end-to-end encrypted,
- decentralized transactions via distributed network
- gateway protocol

## Key Features

## Technology Stack

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/CryptoNexus.git`
2. `cd CryptoNexus`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
